Which tokenless protocol launches biggest?

Every protocol in the sealed DefiLlama snapshot that has no token and is not a wrapped or staked product of something that already trades, ranked by the launch value a token would have on day one. The implied value is the entry’s own claim, worked out from the snapshot’s own figures — TVL, 7-day growth, how long it has run with no token, and how many chains it runs on. Nothing here is a price prediction, and no protocol has promised a token.

How the implied value is worked out

implied = round( TVL × 0.30 × category × growth × maturity × chains )

Category — a stated prior

Lending, CDP, collateral×1.15
Dexs, derivatives, perps×1.12
Yield, yield aggregator, leveraged farming×1.08
Restaking, staking pool, RWA, basis, curators×1.05
Everything else×1.00

Growth — asymmetric

7-day change, clamped to −60%…+120%. A rise counts 0.6 of the move; a fall counts 0.9 of it. Momentum down is the stronger signal. No change recorded counts as 0.

Maturity — time with no token

0.55 at day zero, rising linearly to 1.00 at four years. A protocol that held value for four years without a token launches from strength. Unknown listing date counts as 365 days.

Chains — breadth

+2% per extra chain beyond the first, capped at +16% (8 extra chains).

What is left out, and why

There is no TVL cutoff: the snapshot’s $50M floor is the floor the snapshot itself was selected at, not a ranking rule, so a pre-token protocol below it is still a launch candidate — the board covers all 203 of them. Anything with a live token (a market cap, a CoinGecko id, or a symbol) is set aside on the Already trading tab at the market’s own value — it is not a launch candidate. Bridges, canonical bridges, liquid staking, liquid restaking, restaked BTC and CEX products are excluded because they are wrapped or staked versions of something that already trades, as are versioned re-releases (“Foo v2”) and children of a protocol that already trades. The house watchlist of 40 is always covered: it is the set the brief names, so no watchlist row is dropped by these rules.

Implied value is a model claim, not a price. It says what a launch would be worth if the market priced it like the value already locked in the protocol. A high rank is not a promise that a token exists, that one is coming, or that farming it pays.
