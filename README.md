Token Launch Radar ranks the 203 pre-token protocols in the sealed DefiLlama snapshot by the launch value a token would have on day one, using a stated model — TVL × 0.30 × category × growth × maturity × chains — that a reader can re-derive from the snapshot's own figures. The full house watchlist of 40 is covered, wrapped and staked products of protocols that already trade are excluded, and every ranked protocol gets a 7-step farm plan with a cost and a time. The dashboard is a static, filterable board with a per-protocol detail view (model breakdown included) and a separate tab for the protocols that already trade, shown at the market's own value.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
